# Changelog: language-pack-architecture

## Unreleased

- Created the feature lifecycle record for `language-pack-architecture`.
- Initialized the architecture scaffolding: EARS schema, templates, feature catalog, layout seed.
- Wrote 26 requirements across 7 groups (pack-contract, doc-contract, codec, unit-discovery, version-profiles, settings-surface, write-gate).
- Wrote ADR-0001 … ADR-0007 covering the pack architecture, universal contract, codec, providers, version profiles, registry-driven settings, and the unified check engine.
- Created the `pack-manifest`, `language-profile`, `discovered-unit`, `decoded-documentation`, and `gate-decision` contracts.
- Added the `pack-structure` component and `write-gate-flow` flowchart diagrams.
- Wrote the requirement-mapped test plan (`docs/architecture/test-plan.md`).
- Added the formatter adapter layer: REQ-028…031 in a `formatter-adapters` group, ADR-0004 rewritten around providers plus adapter contracts (`stdin-binary`, `npm-function`, `external-command`), adapter fields in `language-profile.schema.json`, and the FA test series.
- Accepted ADR-0001 … ADR-0007 (all frozen).
- Added the remaining boundary contracts: `profile-resolution`, `formatting-result`, `adapter-candidate`, `dependency-record`, `skill-contribution`, and `settings-entry`.
- Phase 2a: shipped the formatter adapter layer (`stdin-binary`, `npm-function`, `external-command`) in `src/engine/formatters.mjs`; moved Ruff, Biome, and Prettier into formatter-only embedded packs (python, typescript-javascript, docker-compose); deleted the engine's per-tool formatter branches and default pins (rustfmt stays as the documented REQ-028 migration exception).
- Rendered the settings packs group from the registry: one group per pack, per-profile toggles with version ranges, stale-entry rendering, and `packProfiles` policy wiring.
- Phase 1 engine implemented: registry, profile selector, codec, contract engine, tree-sitter/regex providers, and the Lua pilot pack with gate integration.
- Phase 2b skill composition: pack skills moved into `languages/<pack>/skill/` with the pack as the single composition source; the flat `skill/references/*.md` copies were deleted and the client skill index rewritten to render from installed packs.
- Pre-write gate redesigned and re-enabled: the `preWriteGateEnabled` park flag is gone, the `tools/pre-execute` handler is registered unconditionally, and the master switch short-circuits inside the handler and through `createSurfaces` exactly as `docs/architecture.md` documents.
- Gate hardening for large and partially-written files: every child-process stdin write (`checker`, formatter stdin-binary and external-command adapters, project public-unit adapters, and the managed formatter command) carries an error listener so an early-exiting child fails the check as a diagnostic instead of taking the host process down with an unhandled stream error; spawns now receive the validation budget and the execution's own abort signal, so a timed-out or cancelled check kills its children instead of orphaning them; `buildCandidate` resolves relative edit paths against the agent workspace (the pre-edit read previously used the host process directory and silently skipped every relative edit); and the managed formatter command no longer caps pending-content stdout at 200 KB, which had silently truncated the formatted result of larger files.
- Fixed `write_formatted` dying as the harness's opaque "Tool batch execution failed" on every clean file: the inner `tools.execute` dispatch still used the retired single-call shape, while the harness contract is a batch (`{calls: [{id, name, arguments}], signal}` answered with `{results: [{callId, result}]}`), so the executor threw on its own undefined `calls` array and the real cause never reached the agent. The dispatch now builds a proper single-call batch, decodes the batched result, always carries a signal, and wraps dispatcher rejections so the underlying cause is reported instead of lost.
- Removed the stale `Usage:` file-header requirement from the checker: the standard defines the header as Author, Summary, optional Description, and optional Changelog, and none of the golden examples carry a Usage block, yet `checker.py` still blocked every conformant file demanding `Usage:`. All five requirement sites (compose, C/C++, and the three family label sets) now match the standard, and a regression test pins that current-standard headers pass without Usage. `checker.py` itself was also brought under ruff formatting, which had silently drifted and made any edit to the file fail the formatting gate.
- Pack-declared doc syntax (ADR-0008): file-header extraction is now pure pack data. A profile declares its `codec.headerSyntax` — `line`, `block` (open/close tokens, `continuation` marker, `tagSigil` drop rule, and `unlabeled` prose routing) or `docstring` (string prefixes and both triple-quote forms tolerated) — plus per-field spelling lists (string or array; the first spelling renders in missing-field messages) and `preamble.patterns`, anchored regexes skipped ahead of the header such as the Python coding comment. Tree-sitter stays reserved for unit discovery. (REQ-032…036)
- The formatter-only packs (python, typescript-javascript, docker-compose) declared codecs and now own the file header. Gate routing runs the pack header pass for every covered path; a formatter-only pack's unit verdicts stay with the existing passes, and those passes no longer rejudge a header they lost — the checker gained a `--header-covered` flag that suppresses header label checks while keeping Python public-unit and Compose service checks. (REQ-037)
- The header contract converged to Author and Summary: the pack contract dropped the Description requirement and the Usage-must-reference-a-unit check, and missing-field messages render the pack's first declared spelling, preserving the checker's message shapes (`Missing '@author' in file header`, `Missing 'Author:' in file header`). (REQ-038, superseding the Description clause of REQ-005 and the usage rule of REQ-007)
- Profiles declare `policyLanguage` so the per-language policy master switch gates pack coverage exactly as it gated the legacy checker, and `packForPath` now matches `filenames` as well as extensions, so codec-carrying packs resolve filename-matched paths such as `compose.yaml`.
